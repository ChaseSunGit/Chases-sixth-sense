# fabrication files
This folder contains the Gerber file, Pick-and-place (P&P) file, and Bill of materials (BOM) for the PCB design. These files can be directly uploaded to JLCPCB's PCB manufacturing service for printing and assembly. Make sure to select standard assembly with SMT on both sides.

## DISCLAIMER
The fab files in this folder only contains a single sensor PCB and should not be directly ordered. The files are presented as reference only. To actually order the PCBs, go to the panelized folder in order to request multiple boards to be printed and assembled together. Panelization is a SIGNIFICANTLY MORE economical option compared to single PCBs and will drastically lower the single unit cost of each sensor.
